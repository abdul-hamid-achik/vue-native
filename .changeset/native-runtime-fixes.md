Native runtime fixes across all three platforms (shipped via the CLI's bundled native sources and the republished Android AAR). iOS: `VScrollView` `horizontal` now actually scrolls horizontally (the content view was always laid out width-pinned); `lineHeight`/`letterSpacing`/`textDecorationLine` on `VText` no longer overwrite each other (attributes accumulate per label and survive text/font changes, also fixed on macOS); `forceTouch` fires (its handler view was never added to the hierarchy — same fix applied to macOS pressure and hover tracking); keyframe `scale` animates both axes instead of deforming the view; per-corner border radii apply the last value and reset on removal; `vn_keyWindow` prefers the foreground-active scene; and a missing embedded bundle now shows an actionable DEBUG error overlay instead of a silent black screen. Android: the error overlay is suppressed in non-debuggable (release) host apps — stack traces no longer reach end users; in-flight `fetch()` callbacks can no longer crash the process after the V8 runtime is released; `useBiometry` reports the generic `biometric` type instead of claiming `faceID` on fingerprint devices; the cached FCM push token survives hot reloads; hot reload retries indefinitely with exponential backoff (matching iOS) instead of giving up after ~20s; unsupported `skewX`/`skewY` warn once explicitly; and `useCamera`'s `launchCamera`/`launchImageLibrary`/`captureVideo` are now fully implemented (previously stubs that always errored) with iOS-matching payloads — `scanQRCode` remains iOS-only for now.
